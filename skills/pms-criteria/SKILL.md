# Observable success lines

/pms-criteria — Observable success lines. Numbers optional. One per line.

Phase: **04 Align**. Measure it against reality.

Also invoked as `/criteria`.

## When
Success is still a feeling.

## Reads
Current goal.

## Writes
Criteria the rest of the system will judge against.

## Steps
1. Each line must be observable. Feelings are not criteria.
2. Numbers optional. One per line.

## Will not do
- Will not accept 'be happier' or 'find balance' as a criterion.

## Output
## Criteria
- lines: []
- rejected_as_unobservable: []

## Example
`/pms-criteria I can choose how to spend my time / the relationship allows honest disagreement`

## Doctrine
Observe. Understand. Navigate. Align.

- Provenance: reported | observed | inferred | not established.
- Do not invent progress, probability, or completion percentages.
- Empty is allowed. Gaps stay gaps.
- Forward/drag are relative to a named criterion or destination.
- If live context is not actually available, mark it **missing**.
